This folder is prefixed with `_` so Jekyll/GitHub Pages does not publish it. `robots.txt` also disallows crawling.

**Contents:** original `index.html`, `support/`, `privacy/`, `spotify/`, and legacy screenshot images.

**Not backed up here:** `es/`, `ja/`, `download/`, `promo/`, `share/`, `player/` — those paths were unchanged.
